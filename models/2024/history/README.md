## 原仓库 V5 与当前事件模型

V5 对照源来自 `QMsama/rice-crafish` 提交 `e6fb10876a26d270816f11deea153e3d903f82c3` 的 `代码/面上估算V5（重新耦合）.py`。其 Git blob 为 `2941bea2e98fc8497fe7b76d491420ee27fd9dfa`，本次按 Git blob 算法核验保存的源字节。以下差异依据该文件与当前 `regional_model.py`、`current_2024.json`。

| 计算环节 | 原仓库 V5 | 当前 `current_2024` |
|---|---|---|
| 浓度状态 | 初始浓度 1 mg/L，施肥时把回归 C0 累加到现有浓度，再按当前阶段 k 每日衰减；浓度下限 0.001 mg/L | 共同背景 + 最近一次已响应施肥事件的 `α×C0×exp(−kΔt)`；RCC 另加固定投饵项 |
| α 与 k | C0 直接进入浓度；k 按处理、生育阶段预设 | RM/RCC 分别使用点位率定 α、k；当前区域配置沿用这些处理参数 |
| 施肥日历 | 两处理 6/1 基肥、6/18 分蘖肥，比例 0.7/0.3；施肥日即加入浓度并衰减 | 两处理 6/18、7/6，比例 0.6/0.4；次日响应，均使用 tillering C0 回归 |
| 面积与沟渠 | 像元面积常量 20 ha；沟渠比例 0.30、沟长 920 m/ha | 像元面积 4.554342663494959 ha 并由入口核对模板；沟渠比例 855/3100、沟长 285 m/0.31 ha |
| 水分管理 | 日历直接写在脚本中；目标为 0 时按降雨超过 60 mm 的暴雨条件排水/入沟 | 逐日阈值表加配置日历覆盖；晒田标记触发排水；RM 使用 120 mm 田埂阈值和无雨日保水开关 |
| 沟渠损失面积 | ET 和下渗按固定沟渠平面面积扣减 | 按梯形沟水深计算动态湿水面面积，再扣减 ET 和下渗 |
| 运行组织 | 单脚本中固定输入输出路径与情景参数 | 引擎、入口、独立年份配置和小型阈值表；保存输入哈希、参数/事件、代码快照及运行结果 |

以上为两个有明确源身份的实现节点之间的比较。中间历史运行仍按上表的摘要字段管理。区域结果的复现对照和独立观测评价分别记录；本目录提供历史来源与情景定义。
